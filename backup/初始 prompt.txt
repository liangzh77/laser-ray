# 一个双人对战的网页棋类游戏。
在一个区域里面有m*n个格，每个格上都可以有一个物品。物品种类有。
- 1，镜子：激光打到会90°反射，可以转动四个方向。当镜子朝右上的时候，从右边过来的激光会反射到上边，从上边过来的激光会反射到右边，从左边和下边过来的激光会把镜子打掉。
- 2，盾：激光打到会中断，可以转动两个方向。横着的时候会挡住上边和下边的激光，但会被左右的激光打掉。竖着的时候会挡住左右的激光，但会被上下的激光打掉
- 3，激光炮塔：发射激光，可以转动四个方向。朝哪个方向就往哪个方向发射激光。上下左右来的激光都可以把炮塔打掉，炮塔打掉即为游戏结束
- 4，跳台：激光打到会让激光跳过自己和自己身后的一格，可以转动两个方向。如果跳塔在二格，从一格过来的激光会跳过二格和三格，直接从第四格直线向前运动并保持方向不变。竖向的跳塔会被横向激光打掉，横向的跳塔会被竖向激光打掉。
- 5，分光器：分光器有三个有效方向。激光从任意一个有效方向打来，都会分成两路，从另两个方向打出。激光从无效方向打来，可以把分光器打掉。分光器有4个转动方向。比如分光器向上时。左方，上方，右方为有效方向，下方为无效方向。

# 棋盘
- 默认棋盘布局是7×7，棋盘从下往上编号1到7，从左往右编号 a 到 g。黑方棋子的初始位置在6排7排，白方在1排2排。以白方为例，在1排，从左到右分别是竖向的跳台，朝左的分光器，竖向的盾，朝上的激光炮塔，竖向的盾，朝右的分光器，竖向的跳台。2排abc是三个朝右上的镜子，d是横向的盾，efg是三格朝左上的镜子。
- 棋盘还有其他布局，以后再开发。设置可以选择。

# 规则
- 所有棋子都是国际象棋里castle的走法。
- 白先走，轮流下。
- 每步可以选择移动或转动一个棋子，或者发射一次激光。
- 如果激光打掉一个棋子，本回合激光消失。
- 激光炮塔被打掉，玩家判负，游戏结束。

# 时间
- 有三种时间设置，分别是10+0（每人十分钟，用完判负）、15+10（每人十五分钟，每走一步棋加10秒，用完判负）、无限（无时间限制）
