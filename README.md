# 激光棋游戏 - UI 设计演示

这是一个双人对战的网页棋类游戏界面设计演示，展示了完整的用户交互流程和视觉效果。

## 🎮 游戏特色

- **激光物理引擎**: 真实的激光反射、阻挡、跳跃和分光效果
- **5种策略棋子**: 镜子、盾牌、激光炮塔、跳台、分光器
- **多种游戏模式**: 快速对局(10+0)、标准对局(15+10)、休闲对局(无限时间)
- **现代化界面**: 响应式设计，支持桌面和移动设备
- **流畅动画**: 激光发射、棋子移动、界面过渡动画

## 🎯 UI 设计亮点

### 主菜单界面
- 优雅的渐变背景和毛玻璃效果
- 清晰的游戏模式选择
- 动态的激光图标动画
- 现代化的卡片式设计

### 游戏界面
- **信息面板**: 实时显示玩家信息、时间和游戏状态
- **交互式棋盘**: Canvas绘制的高性能棋盘
- **控制面板**: 直观的棋子操作按钮
- **图例说明**: 清晰的棋子类型标识

### 视觉反馈
- 可移动位置高亮显示
- 激光路径动画效果
- 棋子悬停和选中状态
- 游戏结束动画和统计

## 🚀 快速开始

### 方法1: 使用本地服务器（推荐）

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 或者使用简单的静态服务器
npm run serve
```

### 方法2: 直接打开文件

```bash
# 直接在浏览器中打开
open public/index.html
```

或者双击 `public/index.html` 文件。

### 方法3: 使用Live Server（VS Code）

如果你使用VS Code，可以安装Live Server扩展，然后右键点击`index.html`选择"Open with Live Server"。

## 🎨 界面预览

### 主菜单
- 选择游戏模式（快速/标准/休闲）
- 查看游戏规则
- 开始游戏

### 游戏界面
- **顶部**: 玩家信息栏，显示双方玩家和时间
- **中央**: 7×7棋盘，坐标标注(a1-g7)
- **左侧**: 游戏操作按钮和选中棋子信息
- **右侧**: 游戏统计和棋子图例
- **底部**: 游戏控制按钮（暂停、重启、菜单、音效）

### 游戏结束
- 显示获胜方和胜利原因
- 游戏统计摘要
- 重新开始或返回菜单选项

## 🛠️ 技术栈

- **HTML5**: 语义化标记，无障碍访问
- **CSS3**: 现代样式，动画，响应式设计
- **JavaScript ES2022**: 模块化，事件驱动
- **Canvas API**: 高性能棋盘渲染
- **Web Fonts**: Google Fonts (Orbitron, Roboto)

## 📱 响应式支持

- **桌面端**: 完整功能和布局
- **平板端**: 适配触控操作
- **手机端**: 简化界面，竖屏优化
